# ⚡ 8051 Simulator (Web-Based)

🚀 A modern, interactive **8051 microcontroller simulator** built using Flask + JavaScript.

---

## 🔥 Features

* 🧠 Real-time 8051 Assembly Execution
* ▶ Run / Step Execution
* 📊 Live Registers & Flags Visualization
* 🧮 Memory (RAM + ROM) View
* 🌙 Dark / Light Theme Toggle
* ⚡ Fast and responsive UI
* 💻 Fully browser-based (no installation needed)

---

## 🛠 Tech Stack

* Backend: Python (Flask)
* Frontend: HTML, CSS, JavaScript
* Emulator Core: Custom 8051 Instruction Engine

